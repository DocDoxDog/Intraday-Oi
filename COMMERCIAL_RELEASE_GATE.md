# COMMERCIAL RELEASE GATE

Status: BLOCKED

A commercial release requires all of the following evidence:

DATA:
- licensed source access
- canonical PIT-safe ingestion
- valid MarketState
- source/data freshness monitoring

INTELLIGENCE:
- verified news provenance
- transparent priority/impact
- anti-spam
- AI output verification
- scenario lifecycle

CUSTOMER:
- tenant isolation
- entitlement enforcement
- API key rotation/revocation
- usage metering
- notification preferences
- feedback capture

INFRA:
- AWS deployment
- secrets management
- health/ready/metrics
- structured logs
- backups and restore drill
- rollback drill
- Vercel production deployment

COMMERCIAL:
- payment-provider eligibility approval
- terms/privacy/refund policies
- tax/accounting review
- data licensing sign-off
- regulatory/legal review for target jurisdictions

VALIDATION:
- unit/integration/E2E
- OOS/walk-forward for any signal-like component
- paper-trading gates for internal execution system

LIVE TRADING:
DISABLED
