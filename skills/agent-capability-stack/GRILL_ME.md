# Grill Me
Ask one question at a time. Inspect repository/files/components before asking if they can answer it. Provide a recommended answer with trade-offs. Drill the current branch before moving sideways. Track decisions, assumptions, rejected alternatives and unresolved questions. Stop when the next concrete action is unambiguous.
