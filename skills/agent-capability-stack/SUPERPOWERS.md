# Superpowers Adapter
Plan non-trivial work. Isolate substantial changes. Prefer RED-GREEN-REFACTOR. Debug root cause before fixing. Review the diff. Run fresh verification. Report unresolved risk.
Completion contract: requested behavior implemented, relevant tests run and inspected, no unexplained regression, scope matches request.
Never claim success from inference.
