# Skill Creator
Define mission, trigger, inputs, allowed tools, procedure, outputs, failures and verification. Test obvious trigger, near-miss, missing-data, conflict and success cases. Register in the catalog. Lifecycle: draft → tested → active → revised → deprecated.
A skill is a procedure with boundaries and completion criteria, not a persona.
