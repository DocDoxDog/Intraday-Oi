# Content Stack
Research → audience insight → intent → angle → outline → draft → fact check → edit → platform adaptation → distribution → performance feedback.
Content strategy: education, analysis, proof/case study, thesis/opinion, process, product/use case, community.
Editorial: thesis before prose; answer what changed, why it matters, mechanism, evidence, falsifier and implication.
Social: hook → tension → evidence → insight → payoff → CTA; adapt by platform.
Video: hook → promise → beat map → visual proof → narration → pattern interrupts → CTA.
SEO: intent → entity/topic map → supporting questions → evidence → outline → internal links → refresh.
Never manufacture authority, testimonials, results, quotations or statistics.
