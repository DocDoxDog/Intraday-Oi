# Agent Capability Stack
Route: outcome → evidence → specialist skills → synthesis → verification.
Inspect code/data/source before asking questions. Load only relevant specialists.
Separate FACT / DERIVED / ASSUMPTION / HYPOTHESIS / UNKNOWN.
Never let content skills invent facts or let LLMs change deterministic financial values.
Default lanes: Engineering, Research, Data, Product, Design, Content, Growth, Sales, Operations, Finance, Risk.
Completion requires fresh verification evidence.
